# KodaLobbyPlugin

Lobby side of the KodaHosting network: server browser GUI fed by the Supabase RPCs, custom
items, `/server`, `/join`, `/link <code>`, `/lobbyadmin` and `/myservers`. Uses the Paper
Transfer API to send players to their server.
