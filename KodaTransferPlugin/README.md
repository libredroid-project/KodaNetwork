# KodaTransfer

Paper plugin that enables the Transfer API for KodaHosting servers and provides `/khub`.

* keeps `accepts-transfers=true` in `server.properties`
* `/khub` sends the player to the lobby (address configurable in `config.yml`)
* adds a short hint to the server list entry
